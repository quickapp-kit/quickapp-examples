# Gallery-001

Gallery-001 is the V1 device inspection and task-board baseline. It is an
embedded-oriented multi-page QuickApp, not a photo wall.

## Coverage

- Home and Detail pages
- Three keyed inspection entries on the first render, with deterministic reorder/status changes after refresh
- Three small local PNG images used by the status summary and inspection rows
- Deterministic state refresh with `if` status switching and keyed reorder
- Local deterministic inspection summary; device information is not required
- `system.prompt.showToast()` results for refresh, open and back
- `router.push()` and `router.back()`

## Source

```text
src/manifest.json
src/app.ux
src/pages/Home/index.ux
src/pages/Detail/index.ux
src/assets/images/inspection.png
src/assets/images/inspection-review.png
src/assets/images/inspection-alert.png
```

The source uses alliance-compatible DSL. The runtime must consume the RPK
generated by Toolkit; no Page IR or runtime transaction is handwritten here.
All inspection data is local and deterministic. Device information is not a
prerequisite for this basic Showcase.

## Build

From this directory:

```text
node scripts/build-gallery.mjs
```

The deterministic output is written to `dist/gallery-001.rpk` with metadata in
`dist/gallery-001.json`.

## LVGL smoke run

From `quickapp-examples/`:

```text
SDL_VIDEODRIVER=dummy ./build-m1-s2/quickapp_lvgl_simulator \
  --rpk showcases/gallery-001/dist/gallery-001.rpk
```

The interactive simulator keeps the SDL event loop alive. Close the window or
send SIGINT to verify teardown.
